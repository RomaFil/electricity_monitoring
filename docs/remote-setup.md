# Перехід на віддалене керування (прошивка 0.7.0)

Робиться **один раз і лише поруч із платою**: 0.6.1 віддалених оновлень не вміє, тож з Києва її вже не замінити.
Частини 1–3 не потребують світла (плата живиться від ноутбука по USB). Частина 4 — коли світло з'явиться, **ще в селі**.

## 1. ПК (світло не потрібне)

```
cd electricity_monitoring
git fetch origin
git checkout main && git pull          # після злиття гілки claude/busy-clarke-bgvfdb
cd firmware
pip install cryptography
python make_keys.py                    # private.key + public.key
```

- `private.key` — зашифрована копія (KeePass / флешка). У git він не потрапляє.
- `public.key` — закомітити:
  `git add public.key && git commit -m "Firmware signing public key" && git push`

```
python -m platformio run                                  # має бути "Firmware signing: ON" і "Signed: ...firmware.bin.signed"
python -m platformio run -t upload --upload-port COM16    # USB; або по Wi-Fi: python -m platformio run -e ota -t upload
python -c "import secrets;print(secrets.token_urlsafe(32))"   # ключ команд -> у KeePass
```

## 2. Плата (світло не потрібне, з телефона)

- Без відомої мережі плата через 1 хв вмикає точку **SVITLO-LOCAL** (пароль = пароль адміністратора).
  Якщо роутер працює — просто `http://svitlo-local.local/`.
- `http://192.168.4.1/settings` → **«Ключ команд»** → вставити ключ з п. 1 → «Зберегти й перезавантажити».
- `http://192.168.4.1/` → має бути **«Прошивка 0.7.0»** і **«Підпис прошивки: увімкнено»**.

## 3. VPS (потрібен лише інтернет)

- Оновити `server/` на VPS так само, як завжди (з `main`).
- У `~/svitlo-local/.env` додати `ESP_CMD_KEY=<той самий ключ>` (і за бажання `FW_REPO=RomaFil/electricity_monitoring`).
- `docker compose up -d --build`
- Дашборд → картка «Село»: з'являються кнопки «Перезапустити плату» і «Перечитати датчик».

## 4. Перевірка, коли з'явиться світло (ще в селі!)

1. Картка «Село»: **«Прошивка: 0.7.0, підпис перевіряється»** (дані оновлюються раз на кілька хвилин).
2. **«Перечитати датчик»** → за ~2 хв «Остання команда: перечитати датчик, …: датчик перечитано».
3. **«Перезапустити плату»** → за ~2 хв «Остання команда: перезапуск», перезапусків +1, на графіку без хибного відключення.
4. Пробне оновлення:
   - `platformio.ini`: `FW_VERSION=\"0.7.1\"`, `python -m platformio run`, коміт і пуш.
   - GitHub → Releases → новий реліз `v0.7.1` → прикріпити `firmware/.pio/build/nodemcuv2/firmware.bin.signed` **саме з цією назвою**.
   - Дашборд → **«Оновити до 0.7.1»** → за 2–4 хв «Оновлення: 0.7.1 встановлено», «Прошивка: 0.7.1».

Їхати лише після п. 4. Якщо щось не пройшло — USB і локальна мережа є тільки на місці.

## Якщо щось пішло не так

| Що видно | Що це |
|---|---|
| «команда: на платі не задано ключ команд» | п. 2 не зроблено |
| «команда: підпис не збігся» | ключ на платі і `ESP_CMD_KEY` на VPS різні |
| «команда: чекаю точний час (NTP)» | плата ще не отримала час; повторить сама |
| «Оновлення: 0.7.1 не встановилось: …» | текст після двокрапки — причина; плата лишилась на старій версії |
| кнопки «Оновити» нема | у релізі нема файлу `firmware.bin.signed` або GitHub недоступний з VPS |
| збірка пише «private.key is not here» | збирається не на тому ПК, де ключ |
